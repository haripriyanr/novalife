# Cipher moved to NIST SP 800-232 Ascon-AEAD128 — implementation and full re-measure (2026-10-20)

**Owner's decision (2026-10-20):** move the MAC and the placement keystream from Ascon-128 v1.2 to
the standard, and re-measure everything that changes (`docs/improvement_review_2026-10-20.md` A6).
Every tag and the keyed placement change, so the embedded output changes.

## 1. The primitive

`tools/tag_reference/ascon_primitives.py` now implements SP 800-232 Ascon-AEAD128: IV
`0x00001000808C0001`, 128-bit rate, little-endian lanes, p^12 / p^8, DSEP `0x80 << 56`, key added at
S2/S3 before finalisation, and a real duplex decrypt.

| Check | Result |
|---|---|
| official KATs (ascon-c `crypto_aead/asconaead128/LWC_AEAD_KAT_128_128.txt`, SHA-256 `bbbc3469…bd33`, committed under `tools/tag_reference/vectors/kat/`) | **1089 / 1089** encrypt, decrypt, and tamper rejection (tag and ciphertext) |

Two latent bugs went with the old file: a final partial plaintext block was loaded little-endian
inside an otherwise big-endian v1.2, and `ascon_aead_decrypt` recomputed the tag by encrypting
zeros (wrong for any non-empty ciphertext; hidden because its self-check used empty plaintexts).

Command: `novalife_hub/.venv/bin/python tools/tag_reference/ascon_primitives.py`

## 2. RTL

| Core | Simulation | Mutations | Post-synthesis (100 MHz) |
|---|---|---|---|
| `ascon128_aead` (16-byte ciphertext port) | **21/21** bit-exact (19 official boundary KATs, PT/AD 0–32 B, + hub MAC + keystream) | 7/7 caught (old IV 211, old DSEP 70, p^6 167, 0x80 pad 163, key at S1 22, big-endian lanes 212, AD absorbed when empty 55) | **1482 LUT / 739 FF / 0 BRAM / 0 DSP, WNS +5.880 ns** (v1.2: 1422 / 722, +3.210) |
| `tag_engine` | **16/16** + rejects, NO_KEY, BAD_OP, rate limit, wipe | — | **1338 LUT / 869 FF, WNS +4.523 ns** (v1.2: 1325 / 817, +3.821) |
| `enclave_axi` | **16/16** over AXI4-Lite | — | — |

BUILD/VERIFY latency **129 → 119 PL cycles**: the 54-byte associated data is now 4 blocks × p^8
instead of 7 × p^6.
